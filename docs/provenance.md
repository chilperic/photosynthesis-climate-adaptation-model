# Provenance

This repository consolidates postdoctoral modelling code related to C3/C4 photosynthesis, heat balance, hydraulics, sensitivity analysis, and evolutionary trait exploration.

Input archives used for this refactor:

- `photosynthesis_model1.zip`: main coupled photosynthesis/heat/hydraulic/evolution code.
- `models.zip`: historical steady-state model notebooks and generated figures.
- `lab_rotation-florian-haesen.zip`: lab-rotation teaching/supervision material.

The lab-rotation material should not be presented as sole-authored research output unless authorship, permission, and attribution are clarified.
